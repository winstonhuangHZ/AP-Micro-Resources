# AP Microeconomics 官方课程文件

本目录保存 College Board 官方课程支持文件，当前以 AP Microeconomics CED 的 **Effective Fall 2026** 版本为准。

- `official-ced-clarifications.pdf`：CED 澄清文件。
- `official-course-overview.pdf`：课程概览。
- `official-course-at-a-glance.pdf`：课程结构与单元概览。
- `official-course-at-a-glance-printable-poster.pdf`：可打印课程海报。

官方页面入口：

- [AP Central course page](https://apcentral.collegeboard.org/courses/ap-microeconomics)
- [AP Students assessment](https://apstudents.collegeboard.org/courses/ap-microeconomics/assessment)
- [Past exam questions](https://apcentral.collegeboard.org/courses/ap-microeconomics/exam/past-exam-questions)

来源、大小和 SHA-256 见 [`manifest.csv`](manifest.csv)。文件的再分发和公开发布应遵守 College Board 的具体条款。
