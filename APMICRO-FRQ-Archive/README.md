# AP Microeconomics FRQ Archive

This folder contains released AP Microeconomics free-response materials collected on October 26, 2026.

## Coverage

- 2003–2016: released main papers and Form B papers where available, with official scoring and sample-response materials.
- 2017: official question paper added separately because the mirror index did not include it.
- 2018: released main paper and scoring materials.
- 2019: Set 1 and Set 2.
- 2020: no public released FRQ package was found in the checked archives.
- 2021–2025: Set 1 and Set 2 materials.
- 2026: question paper and the current College Board scoring guidelines.

The archive contains 251 PDFs. The year-by-year listing is in [`INDEX.md`](INDEX.md). `manifest.csv` records the source URL, local path, download status, byte size, and SHA-256 checksum for every file.

## File types

- `question-paper`: released FRQ prompt.
- `scoring-guidelines`: official scoring rubric.
- `sample-responses`: released student responses.
- `commentary` / `reader-report`: official scoring commentary or Chief Reader material.
- `statistics` / `distribution`: score statistics and distributions.

## Source policy

College Board URLs are preferred. Older College Board repository URLs are now partly retired, so the older released PDFs were retrieved through the public OnlyPrepy index mirror. The original PDF copyright notices remain intact; this repository is organized for personal study and archival reference.

Official archive page: https://apcentral.collegeboard.org/courses/ap-microeconomics/exam/past-exam-questions
