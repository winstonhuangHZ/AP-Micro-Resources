# AP Microeconomics 开放教材与课程资料

本目录收录来源清楚、适合本地学习保存的开放教材和大学课程资料。

## OpenStax

- `OpenStax/openstax-principles-microeconomics-3e.pdf`：当前版 Principles of Microeconomics 3e。
- `OpenStax/openstax-principles-microeconomics-ap-courses-2e.pdf`：面向 AP Courses 的旧版教材，书目状态可能已 retired，但仍适合补充 AP Micro 基础和图像。

OpenStax 教材通常采用 CC BY 4.0；使用和再分发时保留署名、版本和版权页。

## CORE Econ

- `CORE-Econ/the-economy-1.0.epub`：CORE Econ EPUB 原文件。
- `CORE-Econ/the-economy-1.0.pdf`：由本地 EPUB 转换生成的 PDF，便于打印和搜索。

转换 PDF 不是 CORE 官方 PDF，内容来自原 EPUB；引用时优先链接 CORE 官方页面。

## MIT OpenCourseWare 14.01

`MIT-OCW-14.01-Fall-2023/` 包含 lecture handouts、lecture notes、problem sets、solutions、midterm 和 final。它是大学程度的微观经济学材料，可用来补充 Unit 1–6 的推导和练习，难度通常高于 AP。

MIT OCW 材料通常按 CC BY-NC-SA 4.0 发布；保留原始版权和许可证说明，商业使用前重新核对页面条款。

所有本地文件的来源、大小、SHA-256 和许可证说明见 [`manifest.csv`](manifest.csv)。
