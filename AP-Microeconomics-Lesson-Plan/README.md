# AP Microeconomics 教案与课时设计

本目录提供一套可直接改编的 AP Microeconomics 教学设计。默认模型是 **18 周、每周 2 次课、每次 90 分钟、共 36 课时**，适合学期制课程；文件内同时给出压缩和扩展方法。

## 文件

- [`framework.md`](framework.md)：课程目标、课堂流程、评价方式、资源配合和备课原则。
- [`course-schedule-36-sessions.md`](course-schedule-36-sessions.md)：36 课时逐节安排，包含目标、活动、练习和课后任务。
- [`unit-lesson-template.md`](unit-lesson-template.md)：单节课模板、板书模板、图像训练模板和 FRQ/MCQ 插入方式。
- [`materials-map.csv`](materials-map.csv)：把每个 Unit 映射到本仓库的 HW、FRQ、MCQ 和开放资料。
- [`LATEX-MEMO.md`](LATEX-MEMO.md)：LaTeX 源文件、PDF、编译命令和同步规则。
- [`latex/AP-Microeconomics-Lesson-Plan.pdf`](latex/AP-Microeconomics-Lesson-Plan.pdf)：已编译的 8 页打印版教案。

## 使用方式

1. 先用 `framework.md` 确定班级的起点、课时和测评节奏。
2. 从 `course-schedule-36-sessions.md` 复制对应周次，替换成学校的日期。
3. 每节课至少保留一个学生产出：图、计算、解释段落、选择题错题记录或 FRQ 小问。
4. 每个 Unit 结束后使用本仓库的 Unit HW、官方 FRQ 和 MCQ 练习做闭环。
5. 不把外部受限题库复制到课件中；对 College Board/AP Classroom 内容使用官方入口或教师分配功能。

## 课时调整

- **18 次课**：每次课合并下面两个连续课时；保留每个 Unit 的测验和最后模拟考。
- **45 次课**：把 Unit 2、3、4、6 的图像和 FRQ 训练各拆成两个课时，并增加 3 次错题讲评和 3 次整套模拟。
- **自学**：把“课堂活动”改成阅读/视频、限时练习、错题复盘和一次口头讲解。
