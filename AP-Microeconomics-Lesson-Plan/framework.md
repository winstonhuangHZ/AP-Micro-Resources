# AP Microeconomics 课程框架

## 1. 课程定位

课程围绕 AP Microeconomics 的六个 Unit 展开：经济学基础、供需、生产成本与完全竞争、不完全竞争、要素市场、市场失灵与政府角色。教学要同时训练三种能力：

1. **概念识别**：知道术语、条件和模型的适用范围。
2. **图像与计算**：能画出、移动和解释图像，能写出计算过程和单位。
3. **经济推理**：能从一个变化推出价格、数量、收益、成本、效率或分配结果，并用完整句子说明。

AP 题目往往把三种能力放在同一题中。例如，题目先给工资变化，再要求移动要素市场图、判断企业成本变化、计算利润，最后解释谁受益。因此每节课都要有“概念—图—计算/文字解释”的连接。

## 2. 学习目标

完成课程后，学生应能：

- 区分稀缺性、机会成本、绝对优势、比较优势和生产可能性边界。
- 用需求、供给、均衡、弹性和税收模型解释市场结果。
- 计算总成本、固定成本、可变成本、边际成本、平均成本、利润和收益。
- 在完全竞争、垄断、垄断竞争和寡头模型中判断产量、价格和利润。
- 解释短期和长期决策、进入退出、规模经济与市场结构。
- 分析劳动等要素市场中的边际收益产品、工资和就业量。
- 识别负外部性、正外部性、公共物品、共有资源和信息不对称。
- 用消费者剩余、生产者剩余、总剩余、无谓损失和效率评价政策。
- 在 FRQ 中清楚标注坐标轴、曲线、均衡点、阴影区域、数值和单位。

## 3. 单节课的 90 分钟结构

| 时间 | 环节 | 学生产出 |
|---:|---|---|
| 0–8 分钟 | Retrieval warm-up | 3–5 道旧知识题或一张无标注图 |
| 8–20 分钟 | 目标与情境导入 | 写出本节的核心问题 |
| 20–42 分钟 | 小讲授与示范 | 完成一张结构化笔记或板书图 |
| 42–62 分钟 | 引导练习 | 小组/同伴完成计算、画图或解释 |
| 62–78 分钟 | AP 风格练习 | 4–8 道 MCQ 或一个 FRQ 小问 |
| 78–86 分钟 | 讲评与错误分类 | 填写错因：概念、图、算术、读题、表达 |
| 86–90 分钟 | Exit ticket | 一句话结论 + 一个仍不确定的问题 |

如果课堂只有 50 分钟，保留 warm-up、示范、一个 AP 小练习和 exit ticket；引导练习与讲评放到下一次课。

## 4. 三条教学主线

### A. 图像主线

学生每次画图必须回答四个问题：

1. 横轴和纵轴是什么？单位是什么？
2. 哪条曲线移动，还是沿曲线移动？
3. 新旧均衡点在哪里？
4. 价格、数量、收益、成本、剩余或效率如何变化？

Unit 2–6 要反复使用同一套图像语言，避免每个 Unit 重新背图。

### B. 计算主线

任何计算题要求写三行：

- 公式或关系式；
- 代入的数值与单位；
- 最终答案及经济含义。

例如利润题不能只写一个数字；要说明“每单位价格/总收益/总成本/利润”分别是什么。

### C. 文字解释主线

FRQ 的解释句使用“因为—所以—结果”的结构：

> 因为边际成本上升，企业在相同价格下的利润最大化产量下降，所以市场供给减少，均衡价格上升、均衡数量下降。

学生需要把图像中的变化翻译成完整句子，不能只写箭头。

## 5. 评价安排

| 节点 | 评价 | 目的 |
|---|---|---|
| 每节课 | Exit ticket | 检查当天的一个关键误区 |
| 每周 | 8–12 题 MCQ + 1 个 FRQ 小问 | 形成性反馈 |
| Unit 1–2 后 | 小测 | 检查基础模型和弹性 |
| Unit 3–4 后 | 中段测验 | 检查成本、竞争和市场结构 |
| Unit 5–6 后 | 综合测验 | 检查要素市场与市场失灵 |
| 考前 3 周 | 计时 MCQ/FRQ | 训练节奏和耐力 |
| 考前 1 周 | 全套模拟 | 暴露最后的知识和时间问题 |

错题必须进入同一个错题表，至少记录：题号、考点、错误原因、正确依据、下次检查日期。只抄答案不算复盘。

## 6. 课堂材料组合

- **官方 CED/课程概览**：确定课程边界和术语。
- **FRQ Archive**：每个 Unit 结束后选历史 FRQ；先独立作答，再用 scoring guidelines 对照。
- **MCQ Practice**：平时使用独立题库和公开练习；官方受限题目通过 AP Classroom/Bluebook 使用。
- **Unit HW**：用于课后熟练度和分层作业。
- **OpenStax / CORE / MIT OCW**：用于补充解释、例题、讲义和大学程度的延伸练习。

## 7. 分层教学

- **基础层**：提供坐标轴、曲线名称、公式卡和半完成图；先做数值简单的题。
- **标准层**：独立完成完整图、计算和一段解释。
- **提高层**：加入政策变化、多个市场联动、长期调整或评价不同政策工具。

同一题可以只改变支架，不改变核心经济关系。这样可以让不同基础的学生讨论同一情境。

## 8. 教师备课检查表

- 本节课的一个核心关系是否能用一张图表示？
- 是否有一个需要学生写出过程的计算？
- 是否有一个要求完整经济解释的题目？
- 是否明确了常见错误？
- 练习是否对应本仓库中可追踪的资料文件？
- 是否留出讲评时间，而不是只增加题量？
