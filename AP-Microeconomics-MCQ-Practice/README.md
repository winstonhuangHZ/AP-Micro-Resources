# AP Microeconomics MCQ Practice

This folder contains publicly downloadable MCQ practice material. The files are practice resources, not a complete archive of official annual College Board MCQ forms.

| File | Type | Notes |
|---|---|---|
| [college-board-ap-microeconomics-course-and-exam-description.pdf](college-board-ap-microeconomics-course-and-exam-description.pdf) | College Board official | Includes the course framework, exam information, sample questions, and answer material. |
| [examtex-ap-microeconomics-practice-exam.pdf](examtex-ap-microeconomics-practice-exam.pdf) | Independent practice | Publicly downloadable practice exam with MCQ and FRQ-style material. The matching worked answer key is delivered by the site through its own access flow and is not included here. |

Online practice banks and mirror leads are listed in [../MCQ-Mirror-Notes.md](../MCQ-Mirror-Notes.md).

The local file manifest with source URLs, byte sizes, and SHA-256 checksums is [manifest.csv](manifest.csv).
