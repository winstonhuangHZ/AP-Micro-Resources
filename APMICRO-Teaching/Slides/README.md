# AP Microeconomics Slides

This folder is reserved for PPT/PPTX and slide-source files. Suggested organization:

```text
Slides/
├── Unit-1/ ... Unit-6/
├── Review/
└── shared/
```

Each deck should record the session number, official objective ID, visual asset filenames, and whether the deck is English or Chinese. The English deck can remain the primary version, with a linked Chinese edition when both are available.
