# AP Microeconomics Handouts

This folder is reserved for student-facing materials. Suggested organization:

```text
Handouts/
├── Unit-1/ ... Unit-6/
├── Review/
└── templates/
```

Each handout should record its session number, official objective ID, answer-key status, and the visual assets it uses. Keep the handout source editable and export PDFs only after the layout is checked.

## Standard lesson handout design

Use [`HANDOUT-DESIGN-SPEC.md`](HANDOUT-DESIGN-SPEC.md) as the canonical reference for a complete one-lesson package. It defines:

- the student handout sections;
- the teacher answer edition;
- the Libertine/Libertinus-based LaTeX setup;
- the shared handout/PPT component IDs;
- graph, accessibility, source, and license rules;
- the build and visual-QA release gate.
