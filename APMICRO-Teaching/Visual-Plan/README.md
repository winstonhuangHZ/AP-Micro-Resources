# AP Microeconomics Visual Plan

- [`visual-plan-36-sessions.md`](visual-plan-36-sessions.md) — a flexible two-to-five-visual plan for every session, plus indicator, government, and banking extension modules.
- [`sources.csv`](sources.csv) — FRED, official course, and Wikimedia Commons discovery sources.
- `assets/` — reserved for later downloaded images, generated charts, diagrams, data snapshots, and exports.

Use two visuals as the minimum lesson set. Add a third, fourth, or fifth visual when a session benefits from another graph, diagram, data panel, historical image, or real-world example. The plan uses FRED for reproducible public-data charts and Wikimedia Commons for historical or real-world image discovery. Record the exact series ID or individual file page and license before an asset enters a handout or slide deck.
