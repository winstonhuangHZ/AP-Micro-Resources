# AP Microeconomics Visual Plan

- [`visual-plan-36-sessions.md`](visual-plan-36-sessions.md) — a flexible two-to-three-visual plan for every session, plus indicator, government, and banking extension modules.
- [`sources.csv`](sources.csv) — FRED, official course, and Wikimedia Commons discovery sources.
- `assets/` — reserved for later downloaded images, generated charts, diagrams, data snapshots, and exports.

Use the first two visuals as the normal lesson set. Treat the third item as an optional context visual and omit it when the chart and concept diagram already carry the lesson. The plan uses FRED for reproducible public-data charts and Wikimedia Commons for historical or real-world image discovery. Record the exact series ID or individual file page and license before an asset enters a handout or slide deck.
