# AP Microeconomics Visual Plan

- [`visual-plan-36-sessions.md`](visual-plan-36-sessions.md) — a flexible two-to-five-visual plan for every session, plus indicator, government, and banking extension modules.
- [`sources.csv`](sources.csv) — FRED, official course, and Wikimedia Commons discovery sources.
- [`assets/data/`](assets/data/) — downloaded public-data snapshots, derived tables, illustrative model data, and the data manifest.
- `assets/` — downloaded images, generated charts, diagrams, data snapshots, and exports.

Use two visuals as the minimum lesson set. Add a third, fourth, or fifth visual when a session benefits from another graph, diagram, data panel, historical image, or real-world example. The plan uses FRED for reproducible public-data charts and Wikimedia Commons for historical or real-world image discovery. Original downloaded images go in [`assets/source/`](assets/source/) with a row in its metadata CSV. A `data-ready` status means the input table is available; the chart still needs final rendering and visual QA.

Rendered charts are graph-only assets. Figure titles, captions, panel titles, classroom purpose, and source or attribution notes belong in the lesson index and LaTeX files, while the image retains the economic axes, curve labels, legends, projection lines, and key teaching markers needed for a standalone graph.
