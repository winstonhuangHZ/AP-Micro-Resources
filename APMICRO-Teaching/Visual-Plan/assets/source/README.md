# Source Images

This folder stores original source image files selected for AP Microeconomics teaching materials. It is separate from generated charts, diagrams, and slide exports.

## Current contents

The first batch contains 30 source images covering Great Depression, bank-run, Wall Street, markets, factories, trade, prices, firms, labor, public goods, banking, and education context. Each image has a row in [`sources.csv`](sources.csv) with its Wikimedia Commons file page, direct file URL, intended lesson use, machine-readable metadata where available, licensing note, byte count, and SHA-256.

## Workflow

1. Find a candidate from a public archive or Wikimedia Commons.
2. Verify the individual file page, author, source, date, and license.
3. Save the original file here with a stable descriptive filename.
4. Record the metadata in `sources.csv`.
5. Create resized or annotated copies later under `exports/`; do not overwrite the source file.

Historical images are discussion prompts and context aids. They should not be used as statistical evidence by themselves.
