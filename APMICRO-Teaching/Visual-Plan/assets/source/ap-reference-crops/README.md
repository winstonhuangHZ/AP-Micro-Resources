# AP Micro graph reference crops

This folder contains small, high-resolution crops from existing AP Microeconomics PDFs. They are kept as **reference-only** material for studying graph composition, curve placement, projection lines, labels, and AP-style visual conventions.

The crops are not original artwork and should not be redistributed as if they were. The source PDF, page number, purpose, and reuse note are recorded in [`metadata.csv`](metadata.csv). The College Board and publisher materials remain subject to their own terms.

Use these references when reviewing locally generated figures. Recreate the economics and design with original matplotlib code in `assets/python/`; do not trace or republish a crop as a generated figure.
