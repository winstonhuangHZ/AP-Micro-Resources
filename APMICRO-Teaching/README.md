# AP Microeconomics Teaching Materials

This folder is the working area for course planning and classroom production.

## Structure

- [`Lesson-Plans/`](Lesson-Plans/) — bilingual 36-session lesson plan, CED objective map, Markdown schedule, and LaTeX/PDF editions.
- [`Handouts/`](Handouts/) — student-facing worksheets, graph practice, formula sheets, and FRQ/MCQ review pages.
- [`Slides/`](Slides/) — future English and Chinese PPT/PPTX decks, organized by Unit and session.
- [`Visual-Plan/`](Visual-Plan/) — visual design index, data-source catalog, and future chart/photo assets.

## Production order

1. Keep the session objective and activity in `Lesson-Plans/` as the source of truth.
2. Use `Visual-Plan/visual-plan-36-sessions.md` to select or generate the session visuals.
3. Build the matching worksheet in `Handouts/`.
4. Build the teacher-facing and student-facing decks in `Slides/`.
5. Add generated assets and source/license records to the visual manifest before using them in public materials.
